Chào bạn! Tôi là một lập trình viên trẻ đầy nhiệt huyết với niềm sâu sắc dành cho lập trình web và thiết kế trải nghiệm người dùng. Đối với tôi, việc viết code không chỉ là giải quyết các bài toán logic, mà còn là quá trình tỉ mỉ tạo nên các giao diện trực quan và dễ sử dụng, hữu ích và thân thiện đến người dùng.

Tôi đặc biệt chú trọng đến tính Clean Code, nguyên lý thiết kế tối giản (Minimalism) và hiệu năng tải trang. Luôn cập nhật các tiêu chuẩn mới của HTML, CSS hiện đại và hệ sinh thái JavaScript để tạo ra sản phẩm tối ưu nhất.

Mục Tiêu Nghề Nghiệp

Lộ trình phát triển bản thân bài bản, rõ ràng từ ngắn hạn đến dài hạn.

🎯
Giai đoạn 1-2 năm tới

Mục Tiêu Ngắn Hạn

  • ✓ Ứng tuyển vào vị trí Frontend Developer Intern / Junior tại môi trường công nghệ chuyên nghiệp.
  • ✓ Áp dụng thành thạo HTML5, CSS3, JavaScript ES6+ và ReactJS để phát triển các tính năng thực tế.
  • ✓ Học hỏi quy trình làm việc chuẩn mực (Git Flow, Code Review, CI/CD, Agile/Scrum) từ các đàn anh dày dạn kinh nghiệm.
  • ✓ Hoàn thành xuất sắc khóa luận tốt nghiệp với đề tài ứng dụng web đạt điểm Giỏi.
🚀
Giai đoạn 3-5 năm tới

Mục Tiêu Dài Hạn

  • ✓ Trở thành một Senior Frontend / Fullstack Engineer có năng lực giải quyết các bài toán kiến trúc web quy mô lớn.
  • ✓ Nắm vững chuyên sâu về tối ưu hiệu năng web (Core Web Vitals), bảo mật frontend và trải nghiệm người dùng UX/UI.
  • ✓ Phát triển năng lực quản lý dự án để đảm nhiệm vai trò Technical Lead dẫn dắt đội ngũ kỹ thuật.
  • ✓ Đóng góp tích cực vào các thư viện mã nguồn mở và chia sẻ kiến thức cho cộng đồng lập trình viên Việt Nam.
